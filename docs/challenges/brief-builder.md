# Challenge Brief Builder

Fill in each section with your sponsor, then download the brief as Markdown. Answers save **in this browser only**. Use *Save to file* to hand a draft to someone else.

!!! tip "Keep the solution out"
    If a sentence tells teams *how* to build it (a tool, an architecture, a feature list), move it to *Directions worth exploring* as an optional idea, or cut it.
