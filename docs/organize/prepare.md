# Prepare

Publish what people need early, so everyone arrives ready to build.

## Do this

1. **Open registration you control,** with the fields partners need. Test it on a phone before marketing starts.
2. **Publish** the challenges, rules, judging criteria, and Code of Conduct.
3. **Send the hackathon guide** one to two weeks out, and provision accounts and credits from the registration list.
4. **Set up** a starter kit or template repo, and a Discord (or similar) with announcements and help channels.
5. **Confirm** judges, mentors, workshops, food, and the venue.
