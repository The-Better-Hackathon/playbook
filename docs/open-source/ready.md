# Get Contributors Ready

The goal: every contributor opens their first pull request within the first hours, not the last.

## Do this

1. **Send a setup guide a week ahead:** a GitHub account, Git installed, each project's development environment, and how to sign the CLA or DCO.
2. **Share a starter kit** with the project list, starter issues, links to contribution guides, and the challenges. See [Starter kits](../library/starter-kits.md).
3. **Run a 30-minute setup session** at the start: forking, branching, commits, pull requests, and how to respond to review.
4. **Pair newcomers with mentors** or experienced contributors.
5. **Welcome non-code contributions** from the start: docs, design, accessibility, testing, translation, and triage.
