An open source hackathon puts open technologies, models, and tools at the center. It combines the two paths from [AfroHacks](../afrohacks/index.md) (build a project, or contribute to open source) with the challenge-led approach from Hack Michigan: real problems, written as briefs, judged against a published test.

## Three ways to take part

| Path | What people do | What counts as done |
|---|---|---|
| **Build with open source** | Build a new project using open source frameworks, models, and tools, released under an open source license | A working prototype in a public repo with a license |
| **Contribute to open source** | Fix issues, write docs and tests, improve design and accessibility, translate | An opened or merged pull request, or an accepted issue |
| **Improve open models and data** | Write evaluations, model and dataset cards, benchmarks, examples, and tutorials for open models and datasets | A published evaluation, card, notebook, or merged contribution |

## Who it's for

| If you are… | An open source hackathon helps you… |
|---|---|
| **A community or meetup** | Give members real, public work for their portfolios |
| **A university or HBCU** | Teach collaboration, code review, and real-world workflows |
| **An open source foundation or project** | Grow and diversify your contributor community |
| **A company or open source program office** | Improve the projects you depend on, and meet future contributors and hires |
