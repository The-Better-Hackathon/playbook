# Keep Contributors Coming Back

The real outcome of an open source hackathon is contributors who stay.

## Do this

1. **Keep reviewing:** ask maintainers to finish reviewing open pull requests within two weeks.
2. **Celebrate publicly:** a post listing every contribution and every new contributor, and a spotlight on each project.
3. **Point people to next steps:** each project's community calls, chat channels, and next issues.
4. **Measure retention:** how many people contributed again at 30 and 90 days, and how many pull requests were merged.
5. **Send projects and partners a report** with those numbers, so they come back next time.
